## 🚦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
git clone https://github.com/your-username/decentralized-provenance-cold-chain-compliance-ledger-on-layer-2-rollups.git
cd decentralized-provenance-cold-chain-compliance-ledger-on-layer-2-rollups
npm install
```

### Environment Setup
Create a `.env` file in the root directory:
```env
PORT=3000
GEMINI_API_KEY=your_gemini_api_key_here
JWT_SECRET=your_jwt_secret_key
```

### Run Application
```bash
# Start development server
npm run dev

# Build for production
npm run build
npm start
```

## 🛡️ Risk Management Matrix
1. **Complexity of ZK-rollup integration with resource-constrained IoT hardware** [High] -> *Mitigation: Perform a feasibility study on lightweight proof generation protocols (e.g., PLONK/Halo2) and utilize simulated IoT environments before hardware deployment.*
2. **Dependency on evolving Layer-2 SDKs and bridge protocols** [Medium] -> *Mitigation: Establish a modular architecture using abstraction layers (e.g., Ethers.js wrappers) to isolate core logic from specific L2 infrastructure providers.*
3. **Inaccurate benchmarking due to simulated network congestion** [Medium] -> *Mitigation: Incorporate standardized load testing tools (e.g., Locust or Hardhat Ignition) to simulate high-concurrency environments and establish a statistical baseline.*
4. **Scope creep during Phase 2 (Implementation)** [Medium] -> *Mitigation: Strict adherence to a MVP (Minimum Viable Product) roadmap; defer advanced features to a 'Future Work' section of the thesis.*
